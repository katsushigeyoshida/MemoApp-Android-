MemoApp
超シンプルなメモアプリ

画面
[新規][次][前][削除][他]
[タイトル(作成開始日付時間)]
[テキスト本文            ]

機能
・作成開始の日付時間をタイトルにしてテキストでメモの内容を記述
・メモは日付順にソートされ、[前]ボタンと[次]ボタンで切り替える
・オプション機能として[他]ボタンから文字サイズの選択と全データ削除などができる
・タッチして指を左右にスライドすることによってページを切り替える

オプション機能
・計算
　テキストの中から数式文字列を抽出して計算する
・挿入
　現在の日時または曜日、時間を文の中に挿入する
・目次
　各ページの先頭行をリスト表示し選択したページに移動する
・共有
　他のアプリにテキストを転送する
　また他のアプリからの共有で転送された文字列も受けられる
・検索フィルタ
　検索する文字列を入力して文字列のあるページだけを抽出する(空入力で戻る)
・最新日付に変更
　編集中のメモを最新の日付に更新する(リストの先頭に移動)
・文字サイズ選択
　文字サイズを変更する(標準 12.sp)
　(編集操作を行うかページを変えると新しい文字サイズが反映される)
・全データ削除
　すべてのデータを削除する

計算機能
　全テキストの中から数式文字列を抽出して計算処理を行う
　'==' から '=' までの数値または数式を抽出して計算し結果を '=' の後ろに挿入する
　四則演算(+,-,*,/)と剰余(%),べき乗(^),階乗(n!)の演算処理が可能
　途中に数値や演算子以外の文字列は無視されるのでコメントとして挿入できる
　先頭が数値で始まる文字列は先頭の数値部分だけを数値として認識し、数値以外で始まる文字列は数値として判断しない

検索機能(フィルタ機能)
　検索キーワードを入力してキーワードのあるページだけ抽出する
　空キーワードで元に戻す

実現方法
・テキスト(TextField)のカーソル位置検出方法
　カーソル位置や選択文字を認識するために Stringではなく TextFieldValue を使う
    //  変数宣言
    val memoText: MutableState<TextFieldValue> = mutableStateOf(TextFieldValue())
    //  文字列
    var text = memoText.value.text
    //  選択位置
    var n = memoText.value.selection.start

    //  TextFieldの設定
        TextField(
            value = memoText,                   //  TextFieldValue
            onValueChange = { memoText = it },  //  memoTextに設定
            modifier = Modifier
                .fillMaxWidth()
                .height(viewModel.memoFieldHeight().dp)
            ,
            textStyle = TextStyle(fontSize = textFontSize)
        )
